### Key Discovery: agent-catalog.json is NOT a Duplicate

`agent-catalog.json` is generated by `generate-agent-catalog.cjs` FROM `agent-registry.json`. It is a simplified view (name, description, skills) for quick agent discovery. `agent-registry.json` is the full registry with capabilities, tools, metadata. Both are needed.

### Key Discovery: self-healing/ is ACTIVE

The self-healing directory is actively used by live hooks (`anomaly-detector.cjs` in `hooks/self-healing/`, `loop-state-manager.cjs` called by `pre-task-unified.cjs` and `post-task-unified.cjs`). Only the archived `auto-rerouter.cjs` is dead. The state files are actively maintained.

### Key Discovery: sessions/ is WIRED

The consensus-voting skill workflow and swarm-coordinator both use `.claude/context/sessions/` for session state. It is empty because no consensus vote has been triggered yet, but the wiring is active.

### Key Discovery: backups/ is WIRED

`saga-coordinator.cjs` creates backups on-demand when saga rollbacks are needed. The directory being empty just means no sagas have failed yet.
