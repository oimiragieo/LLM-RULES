## Key Learnings Documented

### 1. Skills Index Generator - Recursive Scanning (SKL-001)
- Use `scanSkillFilesRecursively()` for nested directories
- Preserve full relative paths
- Validate index against filesystem

### 2. Hook Metrics Collection - Stdin Pattern (RS-003)
- Claude Code hooks receive input via stdin, NOT argv[2]
- Always use `parseHookInputAsync()` for modern Claude Code

### 3. Creator State TTL Alignment (CRIT-001, CRIT-002)
- Use single constant `DEFAULT_TTL_MS = 180000` (3 minutes)
- All 6 creator pre-execute hooks must use same TTL
- Post-execute hooks MUST implement cleanup

### 4. Reflection Queue - Step 0 Blocking (RS-001)
- Reflection requests accumulate in `reflection-spawn-request.json`
- Step 0 guard blocks TaskList when pending reflections exist
- Safe to clear stale reflections for historical tasks

### 5. Entity Linking - Session Context
- Entity linking is triggered by memory extraction pipeline
- Low relationship count is expected if extraction hasn't run frequently
- Working as designed - not a bug

### 6. Workflow Registry - Centralized Discovery (WF-001)
- Generator script at `.claude/tools/cli/generate-workflow-registry.cjs`
- Detects workflow types from content
- 36 workflows cataloged

### 7. Audit Methodology - 5-Step Verification
- CODE_EXISTS -> SYNTAX_VALID -> EXECUTION_TEST -> METRICS -> USAGE_EVIDENCE
- Only mark as "VERIFIED_WORKING" after all 5 steps
