## ISSUE: 6 Critical Bugs in Evolution/Reflection Subsystems (2026-03-03)

**Status**: OPEN — Identified by multi-LLM review (Codex + Gemini), Task #4

**Source**: Multi-LLM review of 8 framework files: unified-reflection-handler.cjs, reflection-step0-guard.cjs, evolution state schema/guard/sync, loop-state-manager.cjs, unified-reflection-events.cjs, reflection-spawn-request.json queue

### Bug 1: I/O Bottleneck in generateAndPersistDispatchPlan (CRITICAL — P0)

- **File**: `.claude/hooks/reflection/unified-reflection-handler.cjs`
- **Issue**: `generateAndPersistDispatchPlan()` runs on EVERY PostToolUse invocation, causing escalating latency
- **Impact**: Reflection spawn latency grows with hook invocation frequency
- **Fix**: Gate behind condition — only invoke when new dispatch plan is actually needed (e.g., when reflection queue is non-empty or reflection IDs have changed)

### Bug 2: Timestamp Path Mismatch in trimOldReflections (CRITICAL — P0)

- **File**: `.claude/hooks/reflection/reflection-step0-guard.cjs`
- **Issue**: `trimOldReflections()` uses incorrect timestamp path or field comparison, silently clears entire reflection queue instead of only stale entries
- **Impact**: Valid pending reflections dropped before processing — data loss
- **Fix**: Verify timestamp field name matches schema; add test that confirms queue retained after trimOldReflections on fresh entries

### Bug 3: Evolution State Naming Inconsistency (HIGH — P1)

- **Files**: Evolution guard, evolution schema (gerunds: `evolving`, `reviewing`) vs sync module (verbs: `evolve`, `review`)
- **Issue**: Field naming inconsistency between guard/schema and sync module causes silent state deserialization failures
- **Impact**: Evolution state transitions may silently fail without error
- **Fix**: Standardize all evolution state names — pick gerunds OR verbs, update all 3 files atomically

### Bug 4: Passive Circuit Breaker — No checkAndBlock() (HIGH — P1)

- **File**: `.claude/lib/self-healing/loop-state-manager.cjs`
- **Issue**: `loop-state-manager.cjs` is a passive observer — has no `checkAndBlock()` method; cannot actually prevent runaway loops
- **Impact**: Self-healing circuit breaker is non-functional; escalation thresholds defined but never enforced
- **Fix**: Add `checkAndBlock(agentType, context)` method; call from reflection-handler before spawning new reflection agents

### Bug 5: Memory Poisoning Risk via Regex Extraction (HIGH — P1)

- **File**: `.claude/hooks/reflection/unified-reflection-events.cjs`
- **Issue**: Regex-based pattern extraction on agent output strings can be manipulated by adversarial agent output; no sanitization before writing to patterns.json
- **Impact**: Memory poisoning (ASI06 — OWASP Agentic AI Top 10) — malicious patterns injected into persistent memory
- **Fix**: Apply `memory-sanitizer.cjs` to all extractions; use schema-validated MemoryRecord API only; never write raw agent output directly to memory

### Bug 6: Queue Overflow ID Guard Bug (MEDIUM — P2)

- **File**: `.claude/context/runtime/reflection-spawn-request.json` handler
- **Issue**: ID guard logic drops valid requests when reflection IDs are `undefined` or `null` (falsy) rather than checking length or schema validity
- **Impact**: Valid reflections silently dropped when ID generation fails
- **Fix**: Replace falsy guard `if (!id)` with strict schema check `if (typeof id !== 'string' || id.length === 0)`
