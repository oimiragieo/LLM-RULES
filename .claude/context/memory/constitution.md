# Constitution

This file defines core principles and values for the agent framework.

## Core Principles

1. **Router-First Architecture**: All user requests must be routed via TaskList() + Task()
2. **Memory Protocol**: Agents must read learnings.md before starting, write findings after completing
3. **TDD**: No production code without failing tests first
4. **Verification Before Completion**: Evidence before claims, always
5. **Progressive Disclosure**: Load context incrementally, not all at once
