## Comparison with Other Tools

### vs. Ripgrep (grep)

**ripgrep**: `rg "class" --type js .claude/lib/code-indexing`
- Finds "class" as text (including in comments, strings)
- Fast (~10ms) but includes false positives
- Example false positive: "class name in comment"

**ast-grep**: `sg run -p "class" --lang js .claude/lib/code-indexing`
- Finds only actual class declarations (AST nodes)
- Slightly slower (~30ms) but 100% accurate
- No false positives

### vs. Semantic Search (Phase 1)

**Semantic Search**: "Find authentication logic"
- Understands code meaning
- Returns semantically related code
- ~50ms with embeddings

**ast-grep**: Find functions with 3 parameters
- Finds exact structural patterns
- Doesn't understand meaning
- ~30ms without embeddings

**Combined (Phase 2 Hybrid)**: Best of both worlds
- Semantic understanding + structural precision
- ~80ms total (parallel execution)
