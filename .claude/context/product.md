# Product Context

## Product Summary

Agent Studio is a multi-agent engineering framework for planning, implementation, validation, and operational governance across software projects.

## Problem Statement

Teams need consistent, safe, and testable ways to delegate work to specialized agents without losing quality, traceability, or architectural discipline.

## Target Users

- Core engineering teams adopting agent-assisted workflows
- Platform teams maintaining shared standards and guardrails
- Technical leads coordinating multi-agent delivery

## Product Goals

- Reliable multi-agent execution with clear routing and accountability
- Strong quality gates (tests, lint, format, validation) before completion
- Discoverable, reusable skills/workflows/schemas with low context overhead
- Auditable decisions, learnings, and artifact lineage

## Non-Goals

- Replacing human ownership of architecture/security decisions
- Fully autonomous production changes without review controls

## Success Metrics

- High reference validation pass rate across agents/skills/workflows
- Reduced task cycle time with no increase in regression rate
- Stable token usage through selective context loading and discovery tools
