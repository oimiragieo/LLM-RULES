# Research Synthesis Rules

## Core Principles

- Research before creating any artifact
- Synthesize findings into actionable design decisions
- Minimum 3 sources, 3 Exa queries for Phase O
- All research outputs documented in research-reports/

## Standards

### Research Process

1. Query multiple sources (Exa, documentation, academic papers)
2. Extract best practices and patterns
3. Synthesize into design decisions
4. Document rationale for decisions

### Research Output Structure

```markdown
# {Topic} Research Report

## Sources
- [Source 1 with URL]
- [Source 2 with URL]
- [Source 3 with URL]

## Findings
Key patterns discovered

## Design Decisions
How findings influence creation

## Recommendations
What to implement
```

## Anti-Patterns

- Creating artifacts without research
- Single-source research
- Missing design rationale
- No documentation of research process

## Integration Points

### Related Skills

- All creator skills invoke this FIRST
- `artifact-integrator` - Post-creation validation

## Post-Research Checklist

- [ ] Minimum 3 sources consulted
- [ ] Findings documented
- [ ] Design decisions justified
- [ ] Research report saved to `.claude/context/artifacts/research-reports/`
