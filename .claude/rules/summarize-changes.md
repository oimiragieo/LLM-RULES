# Summarize Changes

Structured workflow for summarizing code changes after completing tasks. Creates clear, actionable summaries of what was changed, why, and what to verify.

## When to Use

Use this skill when working with documentation tasks that require summarize changes.

## Usage

```javascript
Skill({ skill: 'summarize-changes' });
```
