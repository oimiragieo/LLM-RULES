# Modern Python Standards

Use uv, ruff, ty, and pytest. Follow Trail of Bits cookiecutter-python conventions.

## Project Setup (uv)
- `uv init` — new project
- `uv add <pkg>` — add dependency (NOT pip install)
- `uv run pytest` — run tests in managed venv
- Never commit `venv/`, `.venv/`, or `requirements.txt` generated by pip

## Linting & Formatting (ruff)
- `uv run ruff check .` — lint
- `uv run ruff format .` — format
- Configure in `pyproject.toml` under `[tool.ruff]`
- Target: `ruff check --select ALL` with minimal ignores

## Type Checking (ty)
- `uv run ty check` — type check
- All public functions must have full type annotations
- Use `from __future__ import annotations` for forward refs

## Testing (pytest)
- `uv run pytest` — run suite
- Use `pytest-cov` for coverage: `uv run pytest --cov`
- No bare `assert` in production code — only in tests
