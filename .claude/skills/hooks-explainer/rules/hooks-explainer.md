# hooks-explainer Rules

## Purpose

Explain the hook enforcement model without weakening it. The skill should help agents understand where hook failures come from, which docs to read next, and which safe workflow to use instead.

## Rules

- Prefer official repo documentation over memory or guesswork.
- Describe safe workflow alternatives instead of suggesting bypasses.
- Call out whether the failure is about protected paths, pre-tool validation, or completion validation.
- When possible, point to the exact hook or doc file that governs the behavior.
