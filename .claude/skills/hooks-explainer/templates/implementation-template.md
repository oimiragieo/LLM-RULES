# hooks-explainer Implementation Template

## Goal

- Identify the hook category involved.
- Link the relevant docs and implementation entry points.
- Explain the safe remediation path.

## TDD

1. Reproduce the hook failure locally or from CI logs.
2. Identify the governing doc or hook implementation.
3. Update the explanation or contract artifact.

## Verification

- targeted test or exact failing command
- lint / format on changed files
- re-run the relevant validation or workflow gate
