# template-creator Rules

## Purpose

'Creates and registers templates for agents, skills, workflows, hooks, and code patterns. Handles post-creation catalog updates, consuming skill integration, and README registration. Use when creating new template types or standardizing patterns.'

## Best Practices

- Include all required fields with placeholders
- Add documentation comments in templates
- Version templates for tracking changes
- Include validation examples
- Use consistent placeholder format
- Update template-catalog.md after every creation
- Sanitize spawn template placeholders
