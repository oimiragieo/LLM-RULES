# TDD Command

Use TDD for new features and bug fixes.

## Steps

1. Write a failing test that captures the desired behavior
2. Run the test to confirm failure
3. Implement the minimal code to pass the test
4. Refactor with tests green
5. Repeat per behavior

## Output

Provide:
- Test file(s) created/updated
- Test results
- Implementation notes
