# Azure DevOps Skill Workflow

## Skill Location

`.claude/skills/azure-devops/SKILL.md`

## Invocation

- /azure-devops
- node .claude/skills/azure-devops/scripts/main.cjs --help

## Prerequisites

Set environment variables:

- AZURE_DEVOPS_EXT_PAT
- AZURE_DEVOPS_ORG
- AZURE_DEVOPS_PROJECT

## Common Workflows

### Pipeline Automation

- Run and monitor CI/CD pipelines
- Manage pipeline variables
- Handle multi-stage deployments

### Work Item Management

- Create and update work items
- Query with WIQL
- Sprint and iteration tracking

### Repository Operations

- Create and manage pull requests
- Branch policy enforcement
- Code review workflows
