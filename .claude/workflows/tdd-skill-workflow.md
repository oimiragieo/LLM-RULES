# tdd Skill Workflow

1. Capture task goal and define scenario backlog.
2. Select one scenario and write one runnable failing test.
3. Prove RED with command evidence.
4. Implement minimal GREEN patch for that scenario.
5. Prove GREEN with command evidence.
6. Optionally refactor while preserving green.
7. Repeat loop until backlog is complete.
8. Run final checks (tests, lint, format) and anti-test-hacking verification.
